# サムネの型（日常研究所）

## 前提：作りは最低ライン、当たりは題材
- 同じジャンル9局の上位と下位を並べると、**同じ局では当たりも外れも同じ作り**だった（docs/サムネの型_2026-10-22.md）。
- 作りを整えるのは、このジャンルに入るための条件にすぎない。100万と1万を分けるのは、**題材と言葉**（誰でも知っている名前・いま起きている話・対立・お金と数字）。
- だから、サムネだけ磨いて題材を後回しにしない。

## 最低ラインのチェックリスト（全部そろえる）
1. **見出しの帯**
   - 黒地に極太の白文字、8〜14字。1語だけ赤か黄（head_hi）。
   - 型は「原因・対立＋名前」（例：「借金で潰れた そごう」「2万円の発明に604億円」）。
2. **前後2コマ**
   - 左は前（絶頂・発端）、右は後（転落・結果）。
   - 各コマの上に**札**（年＋数字か状態、11字以内）を置き、**橙の矢印**でつなぐ。
3. **コマの背景は場面の絵**
   - その回のドラマ背景（assets/backgrounds の自作）を使う。縞・単色は使わない。
   - 転落の後のコマは `tint: mono`（白黒）か `blue`。
4. **吹き出しに台詞**（9字以内）
   - 相手役の台詞・宣告を優先し、言った人の名札（by）を付ける。
   - 怒鳴り・却下は `shout: true`。
   - **台本にある台詞か、その要約だけ**にする。存命の人の言葉は公の発言どおり。
5. **表情の変化**
   - 前は surprised / happy＋sparkle、後は sad＋gloom か surprised＋shock。
6. **数字は赤**
   - 札の中の数字・万・億・％・割は自動で赤になる。
7. **数字は1枚の中でそろえる**
   - 見出し・札・吹き出し・ラベル・題名の数字は、同じ時点の同じ量にする。
   - 2026-10-22 の失敗：青色LED回で、見出しは「2万円の発明」、左のコマは「1万円だけで！？」だった。
     2万円は出願と登録の褒賞の合計で、1万円は出願のときだけの額。
     視聴者には食い違いに見えるので、左のコマを「褒賞は計2万円」に直した。
   - 描いたら、数字を全部書き出して見比べる。
   - 字が枠の中にあるかも見る。見出しが黒帯の下にはみ出す、札や下の帯で字が枠の線にかかる、は失敗。
     2026-10-23 にユーザーが「サムネの文字ズレてない？」と指摘。Noto Sans JP Black は字の上の余白が大きく、
     全部の字が字の大きさの約2割ぶん下に沈んでいた（Windows 移行のあとの全部のサムネ）。
     `font("w9")` で描く位置だけを上げて直した（gen_thumbnails.py の `_InkFont`）。フォントを替えたら同じ点を見る。
8. **小物（prop）は脇役**
   - 場面の絵で何の話か分かるなら無くてよい。足すならコマの内側の下に小さく。

## やらないこと
- 実在の会社のロゴ・店舗の写真・実在の人物の写真・他局のサムネの絵を使う（商標・著作権・肖像）。
- 動画に無い出来事や数字をサムネに書く（釣り）。
  - A/B テストは総再生時間で勝敗が決まるので、釣りは負ける。
  - 中身と合わないサムネは、視聴者の信用も落とす。
- 被害者のいる事件で、被害を絵や台詞にする。
- 1コマに文字を3個以上置く。
  - 168px に縮めると潰れる（2026-09 の3コマ型の失敗）。
  - 1コマは札と吹き出しの2個まで。

## 書き方（scripts/gen_thumbnails.py の SPECS）

```python
"<slug>": dict(layout="scene", headline="借金で潰れた百貨店", head_hi="借金", panels=[
    dict(scene="so_gaikan", tag="1991年 売上日本一", emo="happy", fx="sparkle",
         say="大きな漁礁ほど魚は集まる", by="", prop=None),
    dict(scene="so_gaikan_heiten", tint="mono", tag="2000年 負債1兆8700億", emo="sad", fx="gloom",
         say="税金で救うのか", by="客", shout=True),
]),
```

- `scene`：背景の名前（assets/backgrounds/<名前>.png）。その回の接頭辞（例 sb_・led_）の絵を使う。
- `tint`：コマの色かぶせ。次のどれか。
  - dark（窮地）
  - red（衝撃）
  - blue（冷たい結末）
  - yellow（絶頂）
  - mono（白黒＝消えた）
  - なし
- `tag`：上の札。11字以内。
- `say`／`by`／`shout`：吹き出し。
- `emo`：立ち絵の表情。happy / sad / surprised / angry / thinking / normal。
- `fx`：sparkle / sweat / gloom / anger / shock。
- `prop`：小物の関数名（任意）。
- 字数の上限を超えると `_len_warn` に出る。出たら言い換える。

**B・C 案**も `scripts/ab_variants.json` の `thumb_b` / `thumb_c` に `"layout": "scene"` と同じ項目で書ける。

## 手順
1. 台本ができたら、山場の2場面（前と後）を選ぶ。その場面の背景と台詞・数字を拾う。
2. A を SPECS に、B・C を ab_variants.json に書く。evidence には台本の行を書く。
3. 描き出す。
   - A：`PYTHONPATH=. python scripts/gen_thumbnails.py <slug>`
   - B・C：`PYTHONPATH=".;scripts" python scripts/ab_variants.py render <slug>`
4. **縮小で確かめる**：3枚を 320×180 と 168×94 に縮め、次の3つが読めるかを見る。
   - 見出し
   - 札の数字
   - 吹き出し
5. 投稿したら A/B テストに3案をかける（手順は PUBLISH.md）。勝敗は PUBLISH.md「A/B テストの記録」に書く。

## A/B テストの組み方
- **A**：今の標準。2026-10-22 からは場面型を A にする。
- **B**：本人や相手の言葉を見出しにする断定型。
- **C**：問い型（「なぜ〜？」）。※2026-11-21 公開分からは、サムネの C は言葉型（下の節）。題名の C は問い型のまま。
- 作りの違い（場面型と対立型）を確かめたいときは、題名を同じ型にそろえた回で比べる。
- 勝った型を次の回の A にする。3回続けて負けた型はやめる。
- **2026-11-17 公開分から（方向転換の実験・8本）**：**B を資料型（layout="doc"、キャラなし）にする**。
  - 中身は次の4つ。
    - 右：自作の背景を白黒にして暗くしたもの
    - 左：大きな2行の見出し（白・黄・赤）
    - 左上：赤い札（会社名・事件名）
    - 下：1行の補足（年と数字）
  - 実在の人の写真は使わない。
  - 10/4〜31 のクリック率は日常研究所 1.5%、キャラなしの犯罪チャンネル 3.3% だった。場面型どうしの A/B は、11/02 までにセブン&アイ以外すべて「差なし」。
  - spec の例：`dict(layout="doc", label="長銀の破綻", lines=[[("2度有罪の","w")],[("頭取が","w"),("無罪","y")]], sub="1株3円の配当で逮捕、10年後の最高裁", scene="cg_saikosai")`
  - 字数の目安：見出しは1行8字まで、札は11字まで、補足は20字まで。
- **2026-11-21 公開分から**：**C を言葉型（layout="quote"）にする。「なぜ〇〇？」の問い型サムネはもう作らない。**
  - ユーザーの感想（11/03）：「なぜ〇〇？」は押したくならない。「上に本人の言葉、下に赤で結果」の煽り型のほうが良い。
  - 中身は次の4つ。
    - 上：本人の実際の言葉（白・「」込み・1〜2行）と、小さく出どころ（誰が・いつ・どこで）
    - 真ん中：場面の背景（白黒で暗く）と、主人公を演じるずんだもん（emo は場面に合わせる）
    - 下：赤く光る結果の一言（「→」で始め、数字を1つ）
    - 左上：赤い帯（会社名・事件名）
  - **言葉は会見・判決・著書・会議録・インタビューの原文だけ**。縮めるなら原文の連続した一部だけ。作り言葉は入れない（名誉毀損と規約の危険）。
  - 実在の人の写真は使わない（許諾が無い）。犯罪チャンネルの言葉型（C:\yt-crime の layout="quote"）と同じ見た目。
  - spec の例：`dict(layout="quote", tag="船場吉兆の廃業", scene="sk_kaiken", emo="sad", fx="gloom", quote=["「叱られると思います」"], src="女将・湯木佐知子（2007年12月10日の会見）", result="→ 5か月後、のれんを返上")`
  - 字数の目安：言葉は1行16字まで（2行まで）、出どころは30字まで、結果は14字まで、帯は11字まで。

## 新しい知見が出たら
- 他局の調査をやり直したときは、docs に日付つきで残し、このファイルのチェックリストを直す。
- 「なぜそうしたか」を1行添える。過去の型の失敗の経緯は video-production の SKILL.md「サムネイル」節にある。
