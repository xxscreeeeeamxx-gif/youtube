# 題名と概要欄の型（日常研究所）

## 前提
- 当たり外れを一番大きく分けるのは**題材**（誰でも知っている名前・いま起きている話・対立・お金）。題名は、その題材の引きを最大にする道具。
- 同じ局の中で上位と下位を比べると、題名の形には差がある。概要欄の作りには差がほぼ無い（docs/題名と概要欄の型_2026-10-22.md）。

## 題名

### 一番強い形：「台詞や行動 → 結果」
- 9局のうち7局で、この形が上位に偏る（+18.5pt）。
- 形：`（人・会社）「台詞」→ 結果` または `〜した（会社・人）、その結果…`
- 台詞は**台本にある台詞か、公の発言どおり**の言葉。存命の人の言葉を作らない。
- 例
  - 「大きな漁礁ほど魚は集まる」と店を増やし続けたそごう、8年後に負債1兆8700億円
  - 社内の褒賞2万円で特許を譲った技術者、会社を訴えた結果「対価604億円」
  - 雪印の偽装を告発した倉庫、国から営業停止を受けた結果…
- 「結果」の中身は、動画の中で必ず回収する（釣りにしない）。

### そのほかの決まり
- **先頭を【題材名】で始めない**（7局で下位に偏る）。
  - 題材名は文の中に入れる。
  - 末尾の【ずんだもん解説】は残す。
- **問いだけの題名（「なぜ〜のか？」）を主にしない**（6局で下位に偏る）。
  - 使うなら、結果と組み合わせる（「〜した結果、なぜ〜になったのか」）。
- 誰でも知っている名前を前半に置く。
- 数字は1つまで。
  - 動画の中の数字と同じ時点・同じ量にする（サムネと同じ決まり）。
- 字数は、【ずんだもん解説】を除いて30〜45字。
- 感情語は1語まで（ヤバい・崩壊・悲報など）。
- 「ｗ」は軽い題材だけ。被害者のいる事件・人の死・裁判では使わない。
- 「誕生・歴史・物語・秘話」は使わない（ジャンルで3%、日常研究所は88%だった）。

### 登録のしかた
- 題名 A は `scripts/gen_youtube_meta.py` の `TITLES`。
- B・C 案は `scripts/ab_variants.json` の `title_b` / `title_c`。
- evidence には台本の行を書く。

## 概要欄

### 1行目の引き（`meta.hook_line`）
- 40字までの一文。問いか対比にする。
  - 例：日本一の百貨店「そごう」は、なぜ8年で負債1兆8700億円の破綻に至ったのか。
- ジャンルの1行目は中央値22字。日常研究所の段落（137字）は長すぎる。
- 検索結果や動画の下で最初に見えるのはこの1行。
- 存命の人・被害者のいる事件では、断定や煽りを避けた言い方にする。

### 本文（`meta.summary`）
- 今までどおり。主人公・時代・山場・どう描いたか（再現ドラマ・双方の言い分など）を200字ほどで書く。

### 主な参考資料（`meta.sources`）
- ジャンルの54%が出典を載せている（日常研究所は0%だった）。
- 事実台帳の出典のうち、**公的な資料・判決・会社の公式発表・本人の著書**を3〜6件選ぶ。
- 形は「名前 URL」。
- 個人のブログや、他局の動画は載せない。

### 自動で入るもの（触らなくてよい）
- 目次（章タイトルから）
- 再生リストと登録のリンク
- 脚色の注意書き
- クレジット
- ハッシュタグ

## A/B テストの組み方（題名とサムネを対にする）
- **A**：「台詞→結果」型（2026-10-22 から標準）。
- **B**：今までの【題材名】＋数字型。
- **C**：問い型。
- 勝敗は PUBLISH.md「A/B テストの記録」に書く。3回続けて負けた型はやめる。
- 2026-10-25ごろから、それまでの型（A＝【】型・B＝台詞の断定型・C＝問い型）の結果が出る。結果を読んで、このファイルを直す。

## 確かめること（投稿の前）
- 題名・サムネ・1行目の数字と固有名詞が、台本と食い違っていない。
- 台詞が台本か公の発言どおり。
- 先頭に【】が無い。末尾は【ずんだもん解説】。
- 概要欄に、1行目の引きと参考資料が入っている（`out/youtube.txt` で確かめる）。
